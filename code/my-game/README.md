# Dodge Fall

A simple Python arcade game built with Pygame.

## Setup

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

## Run

```powershell
python main.py
```

## Controls

- **Left / A** — move left
- **Right / D** — move right
- **Esc** — quit

Dodge the falling red blocks. Your score increases for every block you avoid.
